# SalonQ 💇‍♂️

SalonQ is a full-stack MERN application that simplifies salon appointment booking and queue management. It allows customers to book services online, receive OTP verification, and get automated email reminders, while admins can efficiently manage services, bookings, and queue flow.

---

## 🚀 Features

### 👤 Customer

* Register and Login
* Browse salon services
* Book appointments
* OTP-based verification
* Receive confirmation email
* Receive reminder email
* View booking history

### 🛠 Admin

* Login
* Manage services (Add / Edit / Delete)
* View bookings
* Manage tokens
* Monitor queue
* Generate reports

---

## 🏗 Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Other:** JWT, Nodemailer, Cron Jobs
